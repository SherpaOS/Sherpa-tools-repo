# Sherpa Tools

Free tools for Claude from **Sherpa OS**.

## Install

In **Claude Code**:

```
/plugin marketplace add SherpaOS/Sherpa-tools-repo
```

In **Claude Cowork**: Customize → Plugins → **Browse** → **Personal** → **+** →
**Add from repository** → `SherpaOS/Sherpa-tools-repo`

Then install the plugin you want from the list below.

## What's here

**`rv-park-screen`** — screen ONE RV park, MHP or campground from an **address**.
No numbers required. Pulls what is knowable for free — satellite image, RV-vs-MHP
class from the EPA water registry, pad-count proxy, parcel, FEMA flood zone,
wildfire hazard, area crime, owner of record where public — then hands back the
call sheet: exactly what to ask the seller or broker, and why each answer matters.
Anything unavailable is marked **NOT FOUND**, never guessed.

A single property is always a screen. A whole county or market is a different
tool, and running the seller's numbers is a different tool again.

Directional only — not financial advice.
